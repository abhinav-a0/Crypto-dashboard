# 📌 Project Overview

The Crypto Dashboard is a frontend web application designed to showcase cryptocurrency data in an organized and visually appealing format.

This project was created to practice:
- React fundamentals
- Component-based architecture
- Responsive design
- Modern frontend tooling with Vite
- Project deployment workflow

The application is lightweight, fast, and scalable for future enhancements such as:
- Live crypto APIs
- Interactive charts
- Authentication
- Real-time market updates
